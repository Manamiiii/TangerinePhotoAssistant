# Application icon

`tangerine-photo-assistant.png` is the 1024 px transparent master. The Windows launcher uses
`tangerine-photo-assistant.ico`, which contains 16, 24, 32, 48, 64, 128 and 256 px images.

The emblem combines a tangerine silhouette with a camera aperture. It was generated for this project and
post-processed locally to remove the generated checkerboard background and preserve transparent edges.
