# 首次使用与常见问题

本文面向第一次接触项目的用户。建议先按 README 完成 Windows 源码安装，再处理一批确实准备整理的照片。
不要为试用格式化存储卡、移动唯一原片或导入不可信来源的图片文件。

## 选择存储位置

- **照片目录**：应用的活动图库。使用新的空目录最容易理解；存储卡是导入来源，不要把存储卡设为活动图库。
- **工作目录**：SQLite 数据库、报告、人工评价、归档凭据和备份。需要持久保存，不能当缓存删除。
- **缓存目录**：可重建的缩略图。不能包含照片或工作目录，也不能位于照片目录内。

照片目录必须先存在；`init` 只写配置，不创建目录。推荐用 README 的命令生成配置，不要照抄作者的盘符。
不要把整个用户主目录或整个盘符选为其中任何一项。可选 ExifTool、模型与 Lightroom 路径先留空即可。
设置保存后需要重启生效；修改路径不会搬运旧数据库。已有迁移库以数据库记录的活动根为准。

## 接入已有照片，还是从存储卡开始

**从存储卡开始：** 选择“导入新照片”。来源可包含子目录，无需预建待整理文件夹；系统创建独立批次。
确认前显示完整重复组和不支持文件；来源原片保留。名称建议“2026-10-01 · 拍摄主题”。

**已有电脑照片目录：** 如果不想复制照片，可在初始配置中选择这个既有目录作为照片目录，使用“照片图库 → 更新已有文件索引”。
此入口按当前活动根扫描，需选择目标相册，新发现的拍摄单元会进入该相册；它不是任意来源目录的独立导入器。
首次接入多个主题的完整旧图库时，先理解这个范围，不要误以为只扫描所选相册；可在入库后调整相册归属。
不要把本来不在待整理中的旧照片点“归档”当作通用移动功能。

## 如何判断是否归档完成

“复制并导入”完成表示已在待整理中建立索引；还需要点“完成归档”。
预览中应看到正式目标 `类型/年份/相册名/导入-批次编号/原相对路径`。确认后系统先校验，最后才清理本批待整理副本。
没有拍摄年份时使用“日期未知”。已有相册可以追加新批次，不覆盖旧批次同名文件。

视频、XMP/LRF/AAE/THM/SRT/WAV 文件可一起保存。JPG/JPEG 是图库缩略图和对比的主要来源，
没有 JPG 的 RAW 不会因此获得预览。其他图片、视频和附属文件可从相册清单核对路径。
如果直接纳入已在待整理中的目录，重复跳过、不支持和无关文件仍留在那里，不承诺整个待整理清空。

## 失败时怎么做

| 现象 | 检查与恢复 |
|---|---|
| 找不到 `py`、`npm` 或 `git` | 先安装 README 指定的工具并重新打开终端；`py -3.12 --version`、`node --version`、`git --version` 应可运行 |
| 配置已存在 | 不覆盖它；执行 `doctor --config config.toml` 核对，或选择另一个明确的配置文件名 |
| 照片目录不存在 | 先创建准备使用的目录；检查盘符和存储设备，再运行 doctor |
| 缓存与照片/工作数据重叠 | 改用独立缓存目录；不要挪动或删除原目录里的资料来绕过校验 |
| 页面没出现或没有网页资源 | 确认已执行 `npm ci --prefix web` 和生产构建，从仓库以 `pip install -e .` 安装 |
| 端口占用 | 不结束未知进程；检查是否已有同配置服务。CLI 可显式指定其他 `--port`，浏览器也要用对应地址 |
| 目录选择失败 | 手工输入完整绝对路径；选择目录本身不会创建或复制文件 |
| 只看到 RAW/视频数量，没有照片预览 | 核对同批是否有 JPG/JPEG。当前没有 RAW 解码和视频播放能力 |
| 导入显示来源变化、断开或目标冲突 | 保留来源、已复制文件和批次记录；恢复原路径与原内容后继续。不要手工覆盖目标或删除记录强行解锁 |
| 暂停任务挡住其他操作 | 从该任务原入口继续；导入/归档没有自动丢弃选项。不能恢复原条件时，停止写入并报告问题 |
| ExifTool 不可用 | 基础图片浏览仍可用；RAW 扩展参数需要官方 ExifTool。不要下载来路不明的可执行程序 |
| 保存配置失败 | 页面显示具体原因并保留输入；修正后重试。成功前不要假定路径已切换 |

浏览器关闭不会停止服务或后台任务。CLI 启动的服务需在确认任务空闲后回到终端按 Ctrl+C；
独立窗口可用“安全停止服务”。不要在 running/paused 任务期间重启，也不要同时从 CLI 发起其他写入任务。

## 日常保存与隐私

归档校验不是独立备份：请把照片和完整工作目录备份到另一存储设备。
人工数据 JSON 只覆盖部分人工结果，不含照片、相册定义、相册成员或全部模型结果。
已有数据库升级会先创建备份；不要清理升级备份或未完成任务凭据。

原尺寸 JPG、RAW、完整报告和数据库可能含 GPS、路径、备注等私人信息，不适合直接附到公开 Issue。
缩小 JPG 导出会去除 EXIF，但图像内容本身仍可能包含私人信息；导出包也有拍摄时间等清单信息。
诊断优先使用“系统维护”的脱敏诊断包，并在提交前自行检查。
