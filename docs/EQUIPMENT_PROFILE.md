# 器材档案与分析规则

仓库中的 `equipment/profile.toml` 是不含私人设备的中性模板；富士 X 卡口公开目录保存在
`equipment/catalogs/fujifilm-x.toml`。个人器材、页面上的“已拥有 / 未拥有”和备注保存在当前工作目录的
`Equipment/inventory.json`，因此修改应用设置中的工作目录也会切换个人库存。

目录文件是随应用发布的公开参考资料，个人拥有状态不写回仓库文件，也不写入照片、EXIF
或 XMP。图库里识别到但公开目录未收录的型号会作为“EXIF 发现”项目显示，可再手工标记。
库存文件使用版本 2 格式，同时保存拥有状态、自定义设备、对基础档案的个人字段覆盖和
隐藏项目；每次覆盖前会保留 `inventory.backup.json`，旧版只包含拥有状态的文件也会兼容
读取。官方镜头不从公开目录物理删除，不再拥有时改为“未拥有”；EXIF/目录项目可隐藏并
恢复，只有用户自行新增的机身、镜头和附件可以真正删除。目录与 EXIF 型号作为稳定关联
身份保持只读，显示名称、分类、口径和备注仍可编辑。

滤镜系统按“所有已登记滤镜均可用于所有已登记镜头”处理。转接环和口径只作为器材库存记录，不用于推断某张照片是否使用滤镜，也不限制界面中的滤镜选择。

## 镜头用途与分析重点

以下是分析规则的通用示例，不代表作者或用户实际拥有的设备：

| 器材类别 | 分析重点 |
|---|---|
| 大光圈定焦 | 近距离景深、眼部焦点和暗光人物快门 |
| 轻便变焦 | 焦段、可变光圈及防抖能力 |
| 标准变焦 | 手持/三脚架、滤镜与焦段对拍摄参数的影响 |
| 长焦 | 相机抖动、主体运动及空气扰动的区别 |

## 无法依靠 EXIF 自动确认的上下文

以下附件通常需要用户在事件或照片组级别快速标记：

- 柔焦滤镜：高光扩散、反差降低和细节柔化可能是有意效果，不能直接判为失焦。
- ND64：慢快门可能是有意表现流水、云层或人流，不能按普通手持规则评价。
- CPL：可能改变天空、反射和曝光，分析颜色与明暗时需要知道是否使用。
- GND0.9：天空和地面的曝光关系经过光学平衡，不能仅用全局直方图推断现场动态范围。
- 三脚架和快门线：允许远低于手持安全快门，但仍需检查风、地面振动和主体运动。
- 闪光灯与引闪器：离机闪光未必完整写入 EXIF，需要标记灯位、TTL/手动和是否反射/柔光。

## 界面设计要求

- 在导入事件时一次选择本次使用的机身、镜头和附件，自动应用到整组照片。
- 允许对少数照片覆写，例如只给部分风景照片装上 ND 或 CPL。
- 自动读取 EXIF 后，只询问无法确定的配件，不要求逐张录入。
- 不根据镜头滤镜口径自动判断某块滤镜不可能使用。
- 拍摄复盘必须展示所依据的器材信息，并区分“EXIF 确认”“事件标记”“模型推测”。
- 用户未标记附件时，涉及柔化、长曝光和闪光的结论降低置信度。
