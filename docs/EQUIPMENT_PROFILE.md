# 器材档案与分析规则

结构化清单保存在 `equipment/profile.toml`。型号与名称首先按用户提供内容记录；正式参数规则需再根据厂商资料核验。

滤镜系统按“所有已登记滤镜均可用于所有已登记镜头”处理。转接环和口径只作为器材库存记录，不用于推断某张照片是否使用滤镜，也不限制界面中的滤镜选择。

## 镜头用途与分析重点

| 镜头 | 口径 | 分析重点 |
|---|---:|---|
| XF23mmF1.4 R LM WR | 58mm | 大光圈环境人像；检查近距离景深、眼部焦点和暗光人物快门 |
| XC15-45mmF3.5-5.6 OIS PZ | 52mm | 旅行轻便变焦；结合焦段、可变光圈和 OIS 判断参数选择 |
| XF16-80mmF4 R OIS WR | 72mm | 旅行主力与风景；结合 OIS、焦段、滤镜和手持/三脚架状态判断 |
| XF70-300mmF4-5.6 R LM OIS WR | 67mm | 长焦风景、动物和远距离人物；区分相机抖动、主体运动和空气扰动 |

## 无法依靠 EXIF 自动确认的上下文

以下附件通常需要用户在事件或照片组级别快速标记：

- 天芬 1/4 黑柔、卡色 1/4 白柔：高光扩散、反差降低和细节柔化可能是有意效果，不能直接判为失焦。
- ND64：慢快门可能是有意表现流水、云层或人流，不能按普通手持规则评价。
- CPL：可能改变天空、反射和曝光，分析颜色与明暗时需要知道是否使用。
- GND0.9：天空和地面的曝光关系经过光学平衡，不能仅用全局直方图推断现场动态范围。
- 三脚架和快门线：允许远低于手持安全快门，但仍需检查风、地面振动和主体运动。
- V480 与 X3T：离机闪光未必完整写入 EXIF，需要标记灯位、TTL/手动和是否反射/柔光。

## 界面设计要求

- 在导入事件时一次选择本次使用的机身、镜头和附件，自动应用到整组照片。
- 允许对少数照片覆写，例如只给部分风景照片装上 ND 或 CPL。
- 自动读取 EXIF 后，只询问无法确定的配件，不要求逐张录入。
- 不根据镜头滤镜口径自动判断某块滤镜不可能使用。
- 拍摄复盘必须展示所依据的器材信息，并区分“EXIF 确认”“事件标记”“模型推测”。
- 用户未标记附件时，涉及柔化、长曝光和闪光的结论降低置信度。
