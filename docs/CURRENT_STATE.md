2026-08-12 至 2026-08-13 合入的主要变化：

- 首页已移除偏任务管理式的工作流漏斗，只保留图库摘要、最近照片和确实需要处理的异常；空图库显示轻量首次使用说明。
- 首页补充继续上次工作、最近相册和摄影摘要；模块保持独立，为后续显示/隐藏设置预留边界。
- 图库增加质量状态筛选和统计钻取联动。
- 图库筛选改为紧凑工具栏、生效条件标签和分组展开面板，并补充选片状态筛选。
- 相似组支持只看待选，并展示入选进度。
- 人工评分采用乐观更新，降低连续选片等待感。
- 照片详情支持前后键盘切换、JPG+RAW 标识、更完整 EXIF、亮度直方图和分项评分条。
- 统计新增质量、选片、相机、月份等维度及平均技术分。
- 后端保留按页面读取的选片进度，首页不再额外聚合漏斗计数；直方图存储和补充 EXIF 字段保持不变。
- 详情弹层锁定底层滚动并隔离滚动边界，支持关键参数解释、沉浸查看、缩放和可选信息栏。
- 参数解释支持点击外部、关闭按钮和 `Esc` 关闭；枚举型参数列出常见选项与含义，实际英文 EXIF 值显示中文解释并保留原值。
- 相似组编辑状态绑定具体组 ID，切换下一组不会继承上一组的调整界面；各页面只展示属于自身流程的全局任务卡。
- 连拍选片先选择相册，再进入只包含该相册的待选工作区；相册卡显示待选数、总数和完成进度，从相册详情也可直接进入。
- 相册内默认只显示待选组；每次进入相似组都先显示照片对比，不继承上次调整界面。人工拆分保存后直接定位新生成的第一组，单张分组会在保存前提示改放“移出分组”。
- 分组恢复采用“撤销上一次调整”和“恢复自动识别”两级模型，不向用户暴露容易混淆的技术快照列表；对子组重复拆分会保留同一人工批次，可按顺序逐步撤销；即使调整后原组消失，相册工作区仍提供最近一次撤销入口。
- 离开连拍选片后会清除组内对比和调整分组界面状态，再次进入从相册选择开始，避免意外延续未完成的编辑上下文。
- schema 20 增加相似分组前后快照、即时撤销和历史恢复；历史只写 SQLite，不复制或修改照片。
- Python 静态检查配置和若干后台任务实现经过清理。

## 安全边界

- 不修改 `D:\Photo` 中任何文件。
- 未明确授权不得复制、移动、删除、重命名或覆盖真实照片。
- 不自动写入 XMP，不自动操作 Lightroom 目录。
- JPG、RAW 和附属文件作为同一拍摄单元处理。
- 模型只保存建议，不覆盖人工结论。
- 不干扰正在运行的 ComfyUI 或其他 GPU 任务。
- 默认提交并推送功能修改，但提交前必须检查差异、测试和构建。
