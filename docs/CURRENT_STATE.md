## 安全边界

- 不修改 `D:\Photo` 中任何文件。
- 未明确授权不得复制、移动、删除、重命名或覆盖真实照片。
- 不自动写入 XMP，不自动操作 Lightroom 目录。
- JPG、RAW 和附属文件作为同一拍摄单元处理。
- 模型只保存建议，不覆盖人工结论。
- 不干扰正在运行的 ComfyUI 或其他 GPU 任务。
- 默认提交并推送功能修改，但提交前必须检查差异、测试和构建。
