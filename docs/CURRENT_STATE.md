## 定位与上手

Windows 优先的本地照片整理与人工选片工具，适合 JPG 或 JPG+RAW 批量拍摄。
基础流程不需要账号、GPU、模型或 Lightroom。源码采用 GPL-3.0-only；第三方组件保留各自许可。
[README](../README.md) 介绍用途；[Windows 安装](INSTALL_WINDOWS.md) 和 [首次使用](GETTING_STARTED.md) 提供完整路径。
当前适合早期源码试用，尚不宣称签名、跨平台或干净机器验收完成的稳定发行版。

## 已实现的核心能力

- 独立导入页：来源检查、新建/已有相册、复制与 SHA-256 校验、限定本批入库、持久进度和恢复、归档预览。
  JPG/RAW 配对；视频与附属文件一起复制、列出和归档，不提供视频播放或 RAW 解码预览。
  完整重复组跳过，部分新增保留配对组；同名批次不覆盖。已索引但无相册的视频可纳入。
- 相册归档：确认后备份、复制校验、更新索引，再清理本批待整理副本；来源卡保留。
  相册追加只处理新增待整理文件，冲突停止，异常可继续。列表展示待归档/部分待归档/未完成/已归档状态。
- 增量扫描、EXIF、相册、评分、多维标签、人工保留理由、批量管理和 JPG/RAW 导出。
- 连拍候选与视觉相似组、拆组、人工选片、历史恢复；大窗双图对比支持左右/上下/单图切换及同步缩放。
- 详情、直方图、沉浸查看、参数化修图预览、摄影统计和条件关联。
- 技术检测、可选本地模型、风险审计与人工复核。模型不能自动淘汰照片或覆盖人工结论。
- 设备库存、完整性检查、任务异常队列、脱敏诊断、便携人工数据备份恢复。
  人工数据 JSON 不包括照片和完整相册结构，不能替代完整工作目录备份。
- Lightroom 只读预检和准备清单；Windows 独立窗口、安全服务控制与未签名内测包。

## 数据与架构

- 正式分支 `main`；Python 3.12+、FastAPI、SQLite、React/Vite/TypeScript。
- schema 36：持久导入批次及相册文件关联；schema 35：人工恢复提交凭据和设备恢复记录。
  历史升级已核验主备库完整性、外键和既有业务数据一致性，摘要见 `FORMAL_ACCEPTANCE_*.md`。
- 活动根以数据库 `library_state` 为准。扫描访问失败不误标缺失；稳定 Capture ID、路径别名和人工数据须保留。
- 暂停任务占用任务槽；归档、恢复、切库、启动任务及安全退出保持互斥。
  已完成状态后的审计收尾仍可能短暂持有数据库连接，测试释放临时目录前必须等待工作线程退出。
- 图库先分页 ID 再补展示字段；不持有跨页过期评分。顶部完整分页、底部多页时显示简化分页。
- 缩略图最多同时解码 2 张、前端下载 4 张；小图 320px、中大图 640px，对比使用 1280px JPG 预览。
  大缓存可生成小图，不反向放大；维护在响应后执行，受冷却与容量边界约束。
- 当前页空闲 600ms 后串行预取下一页前 8 张缩略图。切页、改筛选、隐藏页面、打开详情或任务非空闲时取消。
  首次未缓存页面仍可能逐张加载，不承诺所有页面瞬时完成。测量方法见 [性能基线](PERFORMANCE_BASELINE.md)。
- 聚合数据按页面加载、写后按领域失效；请求取消及代次保护避免过期响应覆盖。
  草稿离开保护、失败保留与重试、任务串行轮询及退避已有前端回归。

## 运行与开发约束

真实照片写操作须明确授权；不自动写 XMP、操作 Lightroom 或启动模型，不干扰其他 GPU 任务。
路径设置修改不自动搬运数据。写入回归只用自动清理的临时目录，不维护持久演示图库。
启动/重启前读取 health 和 tasks；running/paused 时不得中断，服务未运行也不自动启动。
本机额外保护目录及窗口限制见忽略的 `AGENTS.local.md`。

在仓库根目录只读核对：

```powershell
git status --short --branch
git log -5 --oneline --decorate
git fetch origin
try { Invoke-RestMethod http://127.0.0.1:8765/api/health } catch { "health endpoint unavailable" }
try { Invoke-RestMethod http://127.0.0.1:8765/api/tasks/current } catch { "task endpoint unavailable" }
```

修改后执行 Python 测试、Ruff（src/tests/scripts）、前端测试和生产构建；核对 diff、暂存内容后按授权提交推送，禁止 force push。
