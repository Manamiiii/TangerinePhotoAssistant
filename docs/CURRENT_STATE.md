## 尚未验收或仍需决策

下一阶段应以 Windows 实机验收为主，不先继续扩功能：

1. 验收新照片目录入口和少量照片增量入库。
2. 验收相册管理、筛选、分页、视图尺寸和批量导出。
3. 验收连拍折叠、待选筛选、拖拽拆组、确认和整批恢复。
4. 验收照片详情的键盘切换、EXIF、直方图、RAW 标识和评分条。
5. 验收质量复核筛选、模型建议与人工评分持久化。
6. 验收首页工作流计数和统计钻取结果是否符合实际使用理解。
7. UI 验收稳定后，再决定是否拆分过大的 `webapp.py` 和 `web/src/main.tsx`。

暂不建议：运行新的全量模型分析、写 XMP、自动操作 Lightroom、删除照片，或在 UI 尚未稳定时进行大规模前端架构重写。

## 安全边界

- 不修改 `D:\Photo` 中任何文件。
- 未明确授权不得复制、移动、删除、重命名或覆盖真实照片。
- 不自动写入 XMP，不自动操作 Lightroom 目录。
- JPG、RAW 和附属文件作为同一拍摄单元处理。
- 模型只保存建议，不覆盖人工结论。
- 不干扰正在运行的 ComfyUI 或其他 GPU 任务。
- 默认提交并推送功能修改，但提交前必须检查差异、测试和构建。
