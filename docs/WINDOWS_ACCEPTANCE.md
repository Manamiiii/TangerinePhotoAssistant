# Windows 验收清单

回到正式 Windows 主机后，可按下面顺序验收。除明确标注的步骤外，不需要运行全量分析。

> 状态：2026-08-14 已按本清单完成本轮正式数据验收。以下步骤保留为后续版本回归基线；
> 再次执行写数据库的项目时仍应使用可恢复的测试内容，不得修改真实照片文件。

## 1. 启动与只读状态

1. 双击 `start-photo-assistant.cmd`。
2. 确认打开 `http://127.0.0.1:8765`。
3. 在“系统维护”确认历史原片和活动图库最近结果均为缺失 0、变化 0、新增 0。

## 2. 新照片入口

1. 打开“照片图库 → 更新图库”。
2. 核对目录为 `D:\PhotoLibrary\Photos\待整理`。
3. 点击“在资源管理器中打开”，确认打开正确目录。
4. 暂不放入正式新照片也可以关闭窗口；该操作不会扫描或修改文件。

## 3. 相似照片分组

建议先选不重要的历史相似组测试：

1. 点击“调整分组”，拖一张照片到空白组。
2. 取消，确认分组没有变化。
3. 再次调整并确认，刷新页面，确认结果仍保留。
4. 点击“恢复自动识别”，确认同一次人工调整整体撤销。
5. 再次确认调整，点击保存提示中的“撤销”，确认立即回到保存前状态。
6. 打开“分组历史”，恢复一个较早版本，确认刷新后仍保留；再恢复自动识别，确认历史记录仍可查看。

“移出分组”只改变 SQLite 中的分组覆盖，不移动、删除或改写照片。重新运行视觉分析后，已确认的人工分组仍会保留；只有“恢复自动识别”会撤销它。

## 4. 质量复核

1. 验证“发现问题”“技术分低于 70”“已有模型建议”等筛选。
2. 点击缩略图查看照片详情、EXIF、问题证据和建议。
3. 修改一张测试照片的人工星级并刷新，确认星级持久化。

## 5. 首页、详情与统计

1. 核对首页不再显示强制工作流漏斗，并正确展示图库摘要、最近照片和真正存在的待处理异常。
   同时核对“继续上次工作”、最近相册和摄影摘要；这些入口只读取现有数据，不启动分析。
2. 在照片详情中使用左右方向键切换，确认不会跳出当前照片集合。
3. 核对 JPG+RAW 标识、快门/光圈/ISO/焦距及扩展 EXIF。
4. 核对亮度直方图明确标注基于 JPG，不把它理解为 RAW 动态范围。
5. 核对总分、曝光、清晰度、参数评分条与已有技术结果一致。
6. 从摄影统计点击相机或月份，确认进入的图库筛选正确。
7. 在详情页切换“精简 / 标准 / 完整”，确认高级拍摄信息和富士机内配方按层级显示，刷新后偏好仍保留。
8. 在质量分析页核对“详情数据”待补数量；补全任务只读照片，并支持暂停、继续和安全取消。
9. 在相似组内只排除一张照片，确认该组仍在“待选”；入选一张或全部排除后才离开待选列表。
10. 打开照片详情并滚动到最下方，确认底层图库不移动；切换窄窗口后确认整个详情仍可滚动。
11. 点击“沉浸查看”或按 `F`，验证左右切换、适应窗口、缩放、信息栏和 `Esc` 退出；浏览器全屏按钮应作为可选增强。
12. 点击关键拍摄参数后的问号，确认解释卡片说明当前概念、常见选项和品牌差异；点击外部、关闭按钮和按 `Esc` 均能关闭，`Esc` 不应同时关闭照片详情。
13. 进入组内对比，确认“下一组待选”位于标题区，“调整这一组”位于照片说明区；进入调整页面后不再显示“下一组待选”，取消调整应回到当前组普通对比页。
14. 进入连拍选片后可在“全部相似组 / 相册”之间切换；进入相册后确认默认“只看待选”，待选数、总数、分页和“下一组待选”都限制在该相册。
15. 新建包含至少两张照片的分组并保存，确认页面直接显示新生成的第一组；只有一张照片的分组应阻止保存并提示放入“移出分组”。再次进入该组应先显示照片，而不是调整界面。
16. 连续进行两次人工拆分，等待撤销提示消失后进入当前组的“调整这一组”，依次使用“撤销上一次调整”确认能逐步回退；“恢复自动识别”应一次移除整批人工拆分，且不修改照片文件。
17. 从调整分组页面切换到其他主功能，再次进入连拍选片，确认回到相册选择页，不保留原组或编辑状态。
18. 完成“更新相似分组”后进入质量分析，确认视觉预筛完成消息只在相似组选片页显示。
19. 图库中展开和收起筛选面板，验证生效条件标签可单独移除，“全部清除”会保留相册详情上下文。
20. 完成“更新相似分组”后停留在相似组选片页，确认完成结果可手动关闭，并会在约 8 秒后自动消失；失败结果不自动隐藏。
21. 进入摄影统计，确认头部显示拍摄天数、相册数、质量分析覆盖和平均技术分，不再重复显示连拍选片进度；点击相机、镜头和月份仍可正确钻取。
22. 进入设备管理，在富士 X 卡口目录切换“全部 / 已拥有 / 未拥有”，将一款测试镜头标为已拥有后刷新页面确认保留，再改回未拥有。该操作只写当前工作目录的 `Equipment/inventory.json`。
23. 核对设备页顶部为机身、下方左侧为镜头且默认“已拥有”、右侧为附件；分别用测试内容新增并编辑一项机身、镜头和附件，刷新确认保留，再删除测试项目。官方镜头只切换拥有状态，不应从官方目录消失。
24. 编辑一个 EXIF 已识别设备，确认原始型号不可修改、显示名称和备注可修改，保存后历史拍摄量不变；隐藏后可在“已隐藏设备”恢复。尝试新增同型号机身或镜头时应提示已存在。
25. 关闭或等待已完成任务提示消失后刷新页面，确认同一条完成消息不会再次出现；失败消息仍应保留供排查。
26. 确认质量分析概览固定在页面顶部，下方横向切换“照片质量 / 模型建议 / 运行记录”；提示词版本和结构警告只在运行记录的高级诊断中出现，页面不再重复展示“最近完成”。
27. 在相似组选片中切换“待选 / 已完成 / 人工调整 / 全部”；拆分保存后应直接显示新组，返回列表后可在“人工调整”找到仍生效的修改。首页“待处理”应显示相似组待选数量。
28. 在折叠连拍的相册中点击“选择照片”，打开一张组卡后逐张勾选，确认“人工入选 / 技术推荐 / 全选 / 清空”只影响本次临时选择，最终导出数量与确认数量一致。
29. 在摄影统计切换“概览 / 拍摄参数 / 时间趋势”以及“数量 / 占比”，确认统计值一致且相机、镜头、题材仍可正确钻取。
30. 在应用设置中分别打开照片、工作、缓存和报告目录，确认只能打开当前实际配置目录；在后期输出分别生成“仅人工入选 / 已有评级 / 指定相册 / 全部照片及状态”清单并核对数量。所有清单仍只写报告目录。
31. 分别进入照片图库、相似组选片和质量分析，确认都有横向“全部 / 相册”范围；点击同一相册进入详情后，在“照片 / 连拍选片 / 质量分析”之间切换，确认相册范围不丢失，返回相册时回到相册列表而不是临时调整状态。
32. 升级 schema 21 后打开一张测试照片，在“标签与流程”中多选题材和问题、选择一个工作状态并添加自定义地点；刷新后确认保留。切换工作状态应替换旧状态，不能同时保存两个；这些操作只写 SQLite，并同时作用于对应 JPG+RAW Capture。
33. 在图库筛选中分别选择题材、工作状态、人工问题和地点，确认可与相册、评级和质量条件组合；进入“选择照片”，选两张测试照片后使用“批量标记”，确认添加、移除和状态替换均只影响所选 Capture，刷新与筛选结果一致。
34. 升级 schema 22 后编辑一个隔离测试相册，在“本次拍摄使用的附件”勾选已拥有的脚架或滤镜并保存；刷新后应保持勾选，相册列表显示附件数，设备管理显示“用于 N 个相册”。取消勾选后两处统计应同步归零；全过程只写 SQLite，不修改照片或 EXIF。
35. 升级 schema 23 后打开详情中的评价说明，确认星级、入选/排除和工作状态含义互不替代；工作状态目录不再提供“精选/待淘汰”，尝试自定义新增这两个旧状态应被拒绝。已有旧状态必须仍可显示、保留或移除，不能被升级自动改成选片结论。
36. 升级 schema 24 后，在连拍对比中将一张照片设为入选并勾选“表情差异”或“构图差异”；详情页和摄影统计应同步显示。点击统计理由或在图库筛选中选择该理由，应只显示对应人工入选照片。取消入选或改为排除后理由应清空。该操作只写 SQLite，不触发模型分析或修改照片。
37. 打开一个已有技术评分的相似组，确认默认按“推荐顺序”稳定排列并显示名次与相对理由；切到“拍摄顺序”后应按原序号排列。切换排序、刷新和重新进入都不得改变人工入选/排除，也不得启动新的质量或模型分析。
38. 在包含明显分差的隔离相似组中，确认显示“技术最佳 / 接近备选 / 候选 / 明显技术弱项”层级；弱项标签只能描述已有技术分，不能自动勾选排除。分差不足或未评分时不得武断标记为失败。
39. 在摄影统计概览核对“选片基准”：分母只能是至少有一张人工入选的相似组，Top‑1 表示人工入选包含技术最佳，Top‑2 表示人工入选落在推荐前两名。未处理组和仅全部排除的组不得降低命中率。
40. 打开一张已有 v4 模型结果的隔离照片，确认详情将“观察到什么 / 下次怎么拍 / 后期建议”分开展示，画面问题带置信度和可修复程度，技术证据区分测量结果与规则推测。没有模型结果时只能显示基础技术证据，不得伪造语义复盘；全过程不重跑模型、不写照片。
41. 在摄影统计概览核对“模型观察与后期建议”只按每张照片最近一次已完成结果汇总；点击一个常见模型观察后，图库应显示同名筛选标签并只返回包含该观察的照片。清除筛选后恢复全部照片，过程中不得启动模型任务。
42. 在质量分析同步已有题材结果，确认详情把分析题材标为只读来源，人工题材仍可独立增删；清除分析题材后人工/导入标签必须保留，再次同步应恢复相同结果。将最新模型结果标为“不准确”后，该结果的分析题材应退出统计和筛选。
43. 在摄影统计查看条件性关联，只应显示至少 3 张条件样本且至少出现 2 次的问题；界面必须说明相关性不代表因果。点击关联项后，图库应同时显示模型观察和关联条件，并只返回同时满足两者的照片。
44. 详情页参数化方案可从模型起点载入、归零、保存草稿、标记采用和暂不采用；保存后刷新仍保留，恢复旧版本会新增草稿而不覆盖历史。
45. 参数快速预览只改变缓存预览，正式照片、XMP 与 Lightroom 目录均无写入；界面明确说明不是 Lightroom 精确渲染。
46. 摄影统计“成长趋势”中的人工高星、技术低分、相似拍摄和选片保留率均显示分子/分母；点击月份只进入对应拍摄月。没有人工评级或明确取舍的月份必须显示空值，不能显示误导性的 0%，也不能自动宣称进步或退步。

## 6. 少量真实导入（需要时再做）

只在准备好后，将少量新照片手工复制到“待整理”，再选择或新建相册并运行“更新图库”。这一流程只增量索引并归入相册，不移动或改写新照片。全量质量分析和本地模型分析可继续延后。

## 7. 应用设置

1. 打开“应用设置”，核对配置照片目录与当前实际图库会分别显示。
2. 核对工作目录、缓存、ExifTool、RAW 扩展名及本地模型参数与 `config.toml` 一致。
3. 不必为了验收修改正式路径；如需验证保存，请使用隔离配置启动服务。
4. 保存后应提示重启生效并显示备份；不得移动照片、数据库或缓存。
5. 后台任务运行或暂停时，设置保存按钮应禁用，接口也应拒绝写入。
